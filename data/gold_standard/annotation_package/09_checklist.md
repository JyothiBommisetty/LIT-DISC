# LIT-DISC Expert Annotation: Submission Checklist

---

## Before You Begin

- [ ] I have read the Expert Instructions (01_expert_instructions.md)
- [ ] I have read the Annotation Manual (02_annotation_manual.md)
- [ ] I have attended the Calibration Session (45-60 min)
- [ ] I have confirmed my Expert ID with the research team
- [ ] I have downloaded all 25 passage files
- [ ] I have downloaded the JSON submission template

---

## During Annotation

- [ ] I am annotating in sessions of no more than 8 passages at a time
- [ ] I am taking 10-minute breaks between every 4 passages
- [ ] I am scoring in the prescribed order (S, N, I, Sy, E, Em, O)
- [ ] I am not revising previous scores after moving to the next passage
- [ ] I am using the full 1-7 scale (avoiding central tendency)
- [ ] I am assigning confidence (1-5) for every passage

---

## Before Submission

- [ ] All 25 passages have been scored
- [ ] All 7 axes have been scored for each passage
- [ ] All scores are integers between 1 and 7
- [ ] All confidence values are integers between 1 and 5
- [ ] Passage IDs are correct (SNC-01 through NWC-05)
- [ ] No scores are left blank, null, or as zero
- [ ] Optional notes do not contain identifying information

---

## File Preparation

- [ ] File is valid JSON (tested with a JSON validator)
- [ ] File is named `[EXPERT-ID]_ratings.json` (e.g., `EXPERT-01_ratings.json`)
- [ ] Expert ID in filename matches `expert.id` in the JSON content
- [ ] Date in the JSON is in YYYY-MM-DD format
- [ ] File contains exactly 25 rating objects in the `ratings` array

---

## After Submission

- [ ] I have received a validation report from the research team
- [ ] (If required) I have resubmitted corrections within 7 days
